راهنمای انتشار در GitHub Pages

۱) فایل ZIP را باز کنید.
۲) تمام محتویات داخل پوشه را در ریشهٔ مخزن GitHub بارگذاری کنید؛ یعنی index.html و پوشهٔ assets باید کنار هم باشند.
۳) در پوشهٔ assets چهار عکس و لوگو موجود است. نام فایل‌ها را تغییر ندهید و حروف بزرگ/کوچک را رعایت کنید.
۴) در GitHub به Settings → Pages بروید.
۵) در بخش Build and deployment، گزینهٔ Deploy from a branch را انتخاب کنید؛ Branch: main و Folder: /(root) را بگذارید و Save کنید.
۶) پس از چند دقیقه سایت را باز کنید. اگر نسخهٔ قدیمی نمایش داده شد، صفحه را با Ctrl+F5 تازه‌سازی کنید.
